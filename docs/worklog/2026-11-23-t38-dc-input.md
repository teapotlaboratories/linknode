  - The official USB Type-C spec tables were NOT checked (flagged).
- **Network:** 100k/100k/100k + 100 nF → node = (CC1+CC2)/3.
  - Active CC up to 2.04 V → node ≤ 0.68 V.
  - Effective Rd 5.1k ∥ 150k = 4.93k.
  - Fault: one CC at 5.5 V → 1.83 V, with µA of clamp current through 100k.
  - Parts: R23, R24, R25 (C25741), C22 (C1525).
