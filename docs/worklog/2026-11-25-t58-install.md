## T60: ESP32-C5 module U801 back to 0° (owner: "any better esp32 orientation so it doesnt need a long route?" → "lets try it")
- Why the old route was long: at 180° the module's FSPI IO_MUX pins (IO2 MISO, IO6 CLK, IO7 MOSI, IO10 CS; WROOM-1U datasheet v1.3 Table 3-2 p.14) and EN face east, away from the RV1106. The SPI (52–68 mm) and EN (48 mm) wrapped round the module's south side. The pogo/FPC change never affected this.
- Orientations considered:
  - 90° / 270° don't fit: the module is 22.9 mm wide that way, and its left edge would land on Y501 and J401.
  - At 0°: SPI estimates 13–26 mm; the slow lines grow to ~35–44 mm.
  - The west-side spare IOs are not FSPI pins; IO27/IO28 are strapping pins.
- `hardware/tools/t60_c5rot.py`: U801 turned 180° about its anchor, then moved 0.5 mm west (the anchor is not the pad centre), so the courtyard is identical (155.725–175.555 × 127.645–150.675). C801/R801/C802/C803/R802 get the same transform (+180°), so each stays at its pin. The 10 C5 nets' 110 tracks/vias are removed. DRC: no new violation, parity 0.
- Routing (copy `s15`; `t53_lay.py` by hand, `t47_tidy.py` tried):
  - SPI on top in pin order N→S (MISO, MOSI, CS, CLK). They pass north of R512 at 138.5/138.8/139.05, then step down past the Y501 load-cap net (via 153.185,138.905) to 139.4/139.65/139.9/140.15. MISO climbs at x 155.0 (x 154.5 hit the C501-Pad1 track at 154.35) to pin 4; MOSI to pin 9; CS drops at x 154.85 to pin 12. CLK hops to the bottom (vias 150.75,140.3 → 155.5,139.14) under the others to pin 8. CS/MISO corners chamfered by hand (bend45 could not).
  - EN on its old top path to pin 3, plus a via (155.75,133.35) to R801.2 / C801.1 on the bottom.
  - The router got 4 of the 5 slow lines through, but put vias under the RV1106 edge (147.9,127.7 / 148.0,130.6) and a BOOT diagonal that blocked the rest. With `--no-top` boxes for the U100 interior and the module body, RX/BOOT/HANDSHAKE could not leave their 0.35 mm-pitch pins. Final, by hand, on the proven old F channels:
    - TX: F 127.04 → via (157.0,127.04) → B 128.0 → diagonal → via (175.5,132.9) → F pin 25.
    - RX: F 127.46 → via (156.6,127.46) → B 128.4 → diagonal → via (175.9,134.1) → F pin 24.
    - DATA_READY: router path. F 128.23 → via (156.225,129.43) → B 130.08 → diagonal → via (175.62,135.98) → F pin 23.
    - HANDSHAKE: router path from a hand stub. Via (154.5,125.78) → B x 154.8 → 131.18 → diagonal → via (175.5,138.83) → F pin 21.
    - BOOT: F 130.3 → via (155.35,130.75) → B down x 155.35 → 134.7 (south of the EN parts) → diagonal → R802.2 → via (175.6,147.4) → F pin 15.
    - The five east diagonals are parallel (x−y ≈ 42.6 / 41.8 / 39.6 / 36.8 / 30.3), with no crossings.
